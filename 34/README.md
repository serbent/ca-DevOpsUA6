# 34. Flask


## Additional tasks
### Dockerize a Flask application

Create a Dockerfile for a Flask application.
User gunicorn to run the application.

Build the image and run the container.

Push the image to a container registry.

### Create a Container App
Use terraform to create a Container App.


### Create a pipeline to build, test, push the image and deploy the Container App
Use github actions to create a pipeline to build, test, push the image and deploy the Container App.
